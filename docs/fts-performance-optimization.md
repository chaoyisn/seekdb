## 剩余开销与修改

- 小词数自然语言 DAAT 归并原来逐维、逐文档通过虚函数调用分值累加器。该路径的构造方为自然语言模式固定创建 inner-product 累加器，现在调用同一具体实现，保留原浮点累加顺序、minimum_should_match 检查和状态重置。布尔、函数回查、较多词数和其他归并算法继续走原路径。
- 当无需 BM25、无维度权重、field boost 为 1，且下推过滤严格为同一 MATCH 结果的裸 BOOL 包装时，有效 posting 的正值标记已经蕴含过滤为真，省去重复求值。阈值比较、复杂过滤和需要分值的查询继续求值；没有删除通用 match_filter 或改变结果投影契约。
- 已有命中位图按最低有效位升序遍历，只访问本轮匹配的维度；仍按照原维度顺序累加全部匹配项，保留词权重与匹配数量含义。
- TOKENIZE 参数解析不再单独创建、分配并销毁 arena，而是借用已有求值临时 arena，直到 JSON 结果打包。嵌套 guard 不重置正在使用的 arena。解析器、JSON 属性、字典加载及校验调用保留，每次仍执行实际分词，没有缓存结果。
- FTS 在生成 rowkey/doc-id 映射后，会提交 doc-rowkey 映射、倒排和 doc-word 三个独立辅助表任务。mini 模式构建队列按已配置 CPU 数最多启用三个线程，使三个任务可重叠；单 CPU 为一个，双 CPU 为两个，正常模式仍为原 16。工作区与租户内存预算保留，此调整也影响 mini 模式并发普通 DDL。

内核只修改四个文件。官方数据、SQL、计时、评分、基线及 CI 工作流均未修改。
